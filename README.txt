MANAS COLLEGE RESUME MAKER - DESKTOP VERSION
============================================

No installation needed. Works offline.

WINDOWS (easiest)
  1. Unzip this folder anywhere (for example your Documents folder).
  2. Double-click  Start-Resume-Maker.bat
     The app opens in its own window, like a normal desktop program.
  3. Optional: double-click  Create-Desktop-Shortcut.vbs
     This puts a "Manas College Resume Maker" icon on your Desktop.
  It uses Microsoft Edge (already on Windows 10/11) or Google Chrome.

MAC / LINUX
  Run  Start-Resume-Maker.sh  (Chrome, Edge or Chromium must be installed).
  If it does not start: right-click > Open, or run "sh Start-Resume-Maker.sh".

YOUR DATA
  - Your resume is saved automatically on this computer (inside the app's own profile).
  - Use "Save data" in the app to keep a backup file (.json), and "Load data" to restore it.
  - Do not move or rename the "app" folder after creating the Desktop shortcut.

AI FEATURES
  Job Description resume, AI Help, AI writing and others need internet and your own
  Anthropic API key (add it under "AI settings"). Everything else works offline.

OPTIONAL: BUILD A REAL .EXE
  Open the "build-exe" folder. Install Node.js (https://nodejs.org), then double-click
  build-exe.bat. After a few minutes you get an installer and a portable .exe in the
  "dist" folder. (Needs internet for the one-time build.)
